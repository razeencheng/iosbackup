# 采用 AGPLv3 许可项目源码

iOS Backup 的项目源码采用 `AGPL-3.0-only`，以允许个人和商业使用，同时要求对外分发或通过网络提供修改版本时继续提供对应源码。该选择接受“AGPLv3 不禁止收费或商业使用”的结果，以换取对闭源分发和闭源网络服务修改的约束；容器中第三方组件的许可证和再分发义务仍单独处理。

## Considered Options

- Apache-2.0：有明确专利授权且采用门槛低，但允许闭源派生版本。
- PolyForm Noncommercial：可以禁止商业用途，但不属于 OSI 定义的开源许可。
- GPLv3：提供分发时的 copyleft，但不覆盖仅通过网络提供修改版本的情形。
