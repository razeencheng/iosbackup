# 面向本地单管理员并提供可选内建认证

iOS Backup 定位为本地优先、单管理员 NAS 应用：核心界面完全离线、无遥测，只有管理员显式配置的通知可以出站。内建认证默认关闭并由启动配置显式开启；关闭时只在启动日志和部署文档提醒，不显示持续 UI 横幅。认证开启后默认用户名为 `iosbackup`，可以覆盖；没有提供密码时，每个部署实例生成唯一随机密码，而不是使用所有实例共享的默认密码。

## Consequences

- 未开启认证的实例只能按文档用于可信局域网或 VPN，不能宣传为可直接暴露到公网。
- 无论认证是否开启，秘密字段都不得通过 API 明文返回，危险操作仍需输入校验和防跨站请求保护。
- 官方生产部署资料应明确提供启用认证和 HTTPS 反向代理的路径。
