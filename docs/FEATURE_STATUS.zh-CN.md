# 功能状态

[English](FEATURE_STATUS.md) · [返回 README](../README.zh-CN.md)

`v1.5.0-beta.1` 是 Docker Beta。以下分级描述当前支持边界，任何分级都不能代替独立验证过的恢复方案。

## 核心（Core）

| 能力 | 当前边界 |
|---|---|
| USB 发现与配对 | 首次配对需要设备解锁、USB 连接，并在设备上接受 Trust（信任）。 |
| 手动 USB 备份 | 主要支持的数据路径。保持设备连接，并核实备份确实完成。 |
| 定时备份 | 使用每设备的时间窗、间隔、电量和充电条件；跳过的任务会等下次调度检查。 |
| 只读查看 | 备份信息、文件清单和 CSV 查看不会修改备份；大型备份可能需要数分钟。 |
| 本地 Web UI 与单管理员认证 | 没有遥测或远程前端资源。认证仅面向单管理员，不能让公网暴露变得安全。 |
| 可选通知 | Telegram、SMTP、企业微信、Bark 和 Webhook 仅在显式配置后尽力发送；通知失败不会使备份失败。 |

## 预览（Preview）

| 能力 | 当前边界 |
|---|---|
| Wi-Fi 备份 | 必须先通过 USB 成功配对，保留有效 lockdown 记录，网络可达，且设备行为兼容。长传输可能因休眠或重新连接失败，USB 是回退路径。 |
| 开启/关闭备份加密 | 需要 `IOSBK_SECRET_KEY`、在线且解锁的设备和备份密码。必须在应用外另存设备密码和主密钥。 |
| 修改备份密码 | 需要旧密码、新密码和在线设备。丢失备份密码可能导致加密备份无法使用。 |

预览功能不代表生产稳定。每台设备或系统升级后，都应先用非关键备份验证，再启用定时任务。

## 实验（Experimental，默认关闭）

| 能力 | 默认门禁 | 风险 |
|---|---|---|
| 整机恢复 | 每设备 `restore_enabled=false` | 会修改设备数据；还需要 CSRF 防护和多重明确确认，不是日常灾难恢复承诺。 |
| 本地解包 | `IOSBK_ENABLE_EXPERIMENTAL_OPERATIONS=false` | 只支持具有明文 SQLite `Manifest.db` 的完整未加密备份；会生成第二份文件并占用大量磁盘空间。 |
| 删除本地备份 | `IOSBK_ENABLE_EXPERIMENTAL_OPERATIONS=false` | 输入设备名确认后，不可逆地删除该设备的本地备份。 |

全局实验开关只严格接受 `true`。为 false 时，解包/删除控件不会显示，对应 API 会在访问备份状态或文件系统前返回 `403`。开启开关不会绕过 CSRF、输入校验、并发保护和确认步骤。

在重要数据上启用恢复、解包或删除前，必须先做隔离测试，备份当前 `/backups`、`/configs`、`/var/lib/lockdown`，并准备回滚方案。
