# 查看本地备份信息

[English](backup-browser.md) · [返回操作手册](../OPERATIONS.zh-CN.md)

在设备的 **备份** 页选择标为“当前备份来源”的日期，打开详情，再点“浏览当前备份的文件清单”，即可读取服务器或 NAS 上的当前备份。历史关闭时，使用独立的“当前备份集”入口。手机离线时仍可查看：概况和未加密文件清单直接从本地读取。开始备份、修改备份密码和恢复设备等操作仍需要可用的设备连接。

清单包含路径和元数据，不包含照片、消息或其他文件的内容。清单可读不代表备份可以恢复。备份任务完成、清单可读、文件内容正确和实际恢复演练，需要分别验证。

## 读取与刷新

1. 展开设备卡片，进入 **备份 → 当前来源的详情 → 浏览当前备份的文件清单**。已有备份会在首次打开文件清单时建立索引，应用启动时不会扫描所有设备的备份。
2. 等待本地读取完成，页面会自动显示概况和清单预览。**刷新**会请求重新读取本地备份，无需连接手机。
3. 查看状态条和两个读取时间。概况与清单的更新时间可能不同，例如一次更新只成功读取了其中一项。**最近成功备份**是应用单独记录的成功时间，不是信息读取时间。
4. 若读取失败，检查备份位置、挂载、访问权限和剩余空间，再选择**重试读取**。`—` 表示未知或不可用，不表示数值为零，也不表示未加密。

每次手动或定时备份成功后，应用都会请求后台更新索引。索引更新失败不会改变已经成功的备份结果。刷新期间继续显示此前可用的信息；刷新失败时保留仍与来源匹配的完整旧结果及其原始读取时间。应用重启后保留已保存信息，但在核对当前来源前先按历史信息展示。手机离线本身不会让信息过期。

修改设备的备份目录会选择另一个来源，不会搬迁旧备份，也不会将旧清单归到新目录。备份位置不可访问与已确认没有备份是不同状态。读取不完整或元数据损坏不能被理解为空备份。

## 大小、数量、预览与 CSV

| 项目 | 含义与限制 |
|---|---|
| 备份大小 | 原始备份中普通文件的逻辑大小之和，不是实际分配的磁盘块大小。排除根目录的 `_unback_` 解包输出和应用生成的 `.iosbackup-unback-*` 临时输出。普通隐藏文件及任意 `.tmp` 文件不会仅因文件名被排除。 |
| 清单条目 | 清单记录数量，包含文件、文件夹和链接，不等于备份目录中实际存储的普通文件数量。 |
| 预览 | 最多 5000 条，同时受 16 MiB 预览数据上限限制；达到字节上限时可能不足 5000 条。每页最多显示 200 条。 |
| 搜索 | 只搜索已经加载的预览，没有匹配项不能证明完整备份中没有该文件。刷新和切换语言会保留搜索条件与页码。 |
| 下载完整 CSV | 只有完整清单保存成功并发布后才可下载。导出该已保存版本的全部记录，不限于预览或搜索结果，手机可保持离线。 |

请等待完整清单生成后下载。如果开始下载前，页面显示的版本已被新版本替换，请刷新信息后重试。已经打开有效版本的下载可以继续完成。CSV 记录可能包含带引号的换行，应使用 CSV 解析工具统计记录数，不能直接按文本行计数。CSV 既不是设备数据副本，也不是恢复输入文件。

本地读取器不会跟随符号链接，也不接受特殊文件作为备份输入。遇到不安全的来源会报告读取失败，不会悄悄跳过后宣称大小或清单读取成功。

## 加密备份与数据库状态

加密备份的基本信息可能可读，但本功能**不会解密加密的 `Manifest.db`**。已经保存备份密码，也不代表这里能够读取加密清单。

只有能够匹配到同一备份来源的已保存清单才会显示；对于加密清单，还必须匹配 Manifest 身份。这类历史清单可以来自已有查看接口实际成功完成的一次兼容在线清单查询。页面不会自动重试在线查询或执行解密。失败、未完成，或输出被旧过滤器裁剪、截断、多行改写而无法证明完整的在线查询，不会被保存为完整清单，旧版浏览器内存中的清单也不会迁移。没有有效历史清单时，页面会说明限制，并禁用完整 CSV 下载。

本地 SQLite 读取器还会拒绝非空的 `Manifest.db-wal` 或 `Manifest.db-journal`。这些事务侧车文件中可能包含尚未写入主数据库的记录。请等待备份生成者完成事务和检查点，或使用其完成后产生的稳定副本；不要删除侧车文件来强制读取。此前若有来源匹配的清单，仍可按历史信息保留，但这不能证明当前数据库已被完整读取。

## 持久化、隐私与资源限制

索引保存在配置目录下的 `backup-index/v1/<source-key>/`，容器中通常为 `/configs/backup-index/v1/`。持久化配置卷后，索引可跨应用重启保留。索引目录权限为 `0700`，文件权限为 `0600`。这是文件系统访问权限，**不是加密**：即使设备备份已加密，保存的元数据和 CSV 路径仍为明文。保护配置卷副本与 CSV 下载，公开 Issue 中不要附上未经脱敏的索引文件。

当前内置上限如下：

| 资源 | 上限 |
|---|---|
| 同时运行的本地索引扫描 | 每个应用实例一个，同一来源的重复请求会合并 |
| 单次本地扫描时长 | 15 分钟 |
| 单个 plist 输入及转换后的输出 | 8 MiB |
| 单条 CSV 记录 | 1 MiB |
| 预览 | 5000 条及 16 MiB |
| 单份完整 CSV | 512 MiB |
| 全部来源的索引存储总量 | 2 GiB，包含临时文件和元数据占用 |

这些上限用于控制 NAS 的内存、CPU 和磁盘消耗，目前不是额外的环境变量设置。除了原始备份，还需为索引预留可用空间。预算或存储不足时不会把部分清单发布为完整清单；在条件允许时保留来源匹配的旧结果，并显示更新失败。未加密且可读的备份可以重新生成索引；加密历史清单可能需要另一次实际成功的兼容在线查询才能重建。

实际备份和凭据的保护方法见[加密与密码](encryption.zh-CN.md)、[设备和存储](device-storage.zh-CN.md)与[部署实例备份和恢复](instance-recovery.zh-CN.md)。本地解包仍是独立的[实验操作](experimental.zh-CN.md)。

## 查看任务记录与选择备份模式

进入设备的“任务记录”页签，可按任务类型和结果筛选，再选择某次任务，查看请求模式、执行结果、阶段事件及最近确认的备份活动。记录在重启后保留，设备离线时也可查看；页面刷新和连接心跳不会推进备份活动时间。

页面最多显示最近 1,000 条事件。“复制日志”提供可读文本，“下载日志”提供包含摘要及已保留事件的 JSONL 文件。记录最多保留 30 天，同时受 1,000 个已结束任务、每任务 10,000 条事件 / 1 MiB、总预算 256 MiB 的限制；先达到的限制生效，活动任务摘要另行保护，原子写入需要临时空间。损坏或孤立记录也受期限与容量限制。页面会提示截断、过期或保存失败；下载不会补回已经清理的事件。分享前核对摘要中的设备名称和标识。

点击“立即备份”直接使用自动模式，由设备和工具选择可用方式。需要重新请求完整备份时，打开旁边的 **⋯ → 高级：强制全量备份**，阅读提示后确认。这只影响本次请求，不改变自动计划；实际类型没有可靠证据时显示“未知”。是否保留独立历史版本由历史设置决定，任务记录本身不包含备份数据。备份结束后，设备卡保留成功、失败、停止或中断提示。

## 只读备份检查

每次备份工具成功退出后自动执行轻量检查，期限为 30 秒。检查必要 plist 元数据、`SnapshotState=finished` 完成标记及非空 `Manifest.db` 是否存在，不逐项扫描文件对象。加密备份无需解密清单也可以通过这层元数据检查。

点击 **检查备份** 可在手机离线时执行逐项检查，期限为 15 分钟。对于可读取的未加密清单，普通文件条目必须能找到对应普通文件对象；目录和符号链接不要求存在普通文件对象。未知条目类型、工具缺失、来源无法访问、取消及超时会保留已完成的覆盖范围，不能算作完整通过。页面区分 **检查通过、发现问题、检查未完成或无法检查**。两种检查均不核对所有内容哈希，也不保证真机恢复成功。

检查共用本地扫描容量，并阻止同一设备备份的并发写入。可用 **取消检查** 取消当前扫描。结果写入任务记录，可随日志导出。修改备份来源或再次写入后，旧检查证据标为过期；重启后需重新检查才能确认当前有效性。页面分别显示备份执行、检查和历史保存结果，工具成功不会因检查异常被改写成执行失败。手动检查不发送通知。

轻量检查只显示必要元数据和完成标记的覆盖范围，不显示未执行的逐项扫描计数。取消对应“已停止”，超时对应“已中断”，读取失败对应“失败”；扫描完成但发现问题，仍保留有效的检查结论。最近尝试未完成时，页面可同时展示仍在任务保留范围内的上一次完成结果及其时间、来源有效性。
