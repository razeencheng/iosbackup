# 开始前：确认环境和支持范围

[English](overview.md) · [返回操作手册](../OPERATIONS.zh-CN.md)

## 目标与适用范围

安装前，先确认自己的主机是否满足下列条件，再选择对应的安装指南。本手册面向一人管理、把 iPhone/iPad 备份到家中 Linux 主机或 NAS 的使用场景。先完成一次 USB 备份，再按需逐项配置自动备份、Wi-Fi 和加密功能。

iOS Backup 在主机上调用 iOS 设备通信工具，将备份写入你指定的磁盘；Web 页面用来操作任务和查看状态。它不是云存储服务，也没有替你保存另一份异地副本。备份是否包含所需数据、是否能够读取、是否可以恢复，需要分别验证。

## 操作前准备

| 项目 | 需要确认的条件 |
|---|---|
| 主机 | 可信 Linux 主机，或能安装兼容 Container Manager 的群晖 NAS。镜像构建目标为 `linux/amd64`、`linux/arm64`，仍需确认取得的具体镜像包含你的架构。 |
| 容器环境 | Docker Engine 与可运行 `docker compose` 的 Compose 插件；有管理 Docker 和创建持久化目录的权限。群晖版本要求见[专门指南](synology.zh-CN.md)。 |
| 设备与连接 | 一台可解锁的 iPhone/iPad、知道其锁屏密码、能传输数据的 USB 线，以及实际连接设备的主机 USB 端口。 |
| 存储 | 可写的本地文件系统，有足够空间和 inode；按设备已用容量加余量准备首次备份，另留主机运行空间。备份实际大小可能不同。 |
| 网络 | 浏览器能访问主机，镜像来源可达。Wi-Fi 不是首次安装的必要条件；开启后另行验证网络和设备兼容性。 |
| 凭据 | 能安全保存管理员密码、默认 `secret_key`（或外部主密钥）和已有设备备份加密密码，并准备受保护的离线副本。 |
| 镜像来源 | 使用官方镜像 `ghcr.io/razeencheng/iosbackup`，并记录所用版本或摘要。默认镜像引用见 [compose.yaml](../../compose.yaml)。 |

## 选择路线

1. **普通 Linux 主机** ：阅读[安装、登录和保护访问](installation.zh-CN.md)。所有容器命令都在实际连接手机、保存备份的主机执行。
2. **群晖 DSM** ：阅读[群晖安装](synology.zh-CN.md)。按 NAS 型号、DSM 和 Container Manager 版本确认条件，使用独立部署目录。
3. **Windows 或 macOS** ：本项目不承诺在这些系统原生运行真机备份服务；Docker Desktop 的 USB、主机网络行为也不属于这条教程的验收范围。它们可作为浏览器客户端，或按 [Wi-Fi 指南](wifi.zh-CN.md)用 Apple 工具准备手机。
4. **已有部署** ：保留当前密码、数据目录、所有使用的 Compose 配置文件和外部主密钥，阅读[升级与回滚](upgrade.zh-CN.md)或[实例恢复](instance-recovery.zh-CN.md)。不要重复运行新实例初始化命令。

## 认识权限和数据位置

默认 Compose 使用特权容器和主机网络，挂载主机的 USB 与 udev 信息。特权容器具有很高的宿主机权限，因此镜像和主机都必须可信。默认 Web 监听 `0.0.0.0:9000`；主机网络直接使用宿主机端口，不另设 `ports` 映射。限制访问源，在跨主机访问时优先使用 HTTPS 反向代理或受保护的隧道；不要直接开放公网端口。

安装教程将以下相对路径放在同一个**部署目录** ，它与源码目录可以不同：

| 主机部署目录内路径 | 容器路径 | 用途 |
|---|---|---|
| `data/backups` | `/backups` | 设备备份与可选解包输出 |
| `data/configs` | `/configs` | 设备设置、管理员密码、认证/CSRF 状态、默认主密钥 secret_key、加密通知秘密和已保存备份密码 |
| `data/lockdown` | `/var/lib/lockdown` | 此实例与设备的配对记录 |
| `compose.yaml` | 无 | 镜像、端口、日志等进程参数和数据挂载；普通配置统一在这里修改 |

恢复实例需要三个完整目录、所有使用的 Compose 配置文件和外部凭据。容器镜像、仅导出的 Compose 文件或单独的手机备份目录，都不足以恢复整个实例。详见[实例备份与恢复](instance-recovery.zh-CN.md)。

## 按成熟度使用功能

功能成熟度、默认开关和支持边界统一见[功能状态](../FEATURE_STATUS.zh-CN.md)。本手册按具体任务说明操作前提；先完成 USB 备份测试，再按需配置 Wi-Fi 与加密；会修改或删除数据的功能见[实验操作](experimental.zh-CN.md)。

自动备份表示条件满足时自动发起任务，手机仍可能要求输入锁屏密码。不能假设安装后所有备份都无需人在场。

## 完成标准和失败时的选择

开始安装前，应能回答：在哪台主机运行、使用什么镜像和架构、备份放在哪里、谁能访问页面，以及主机损坏或丢失后，用哪些副本恢复实例。如果有不清楚的地方，先确认后再安装；容器能启动不代表这些条件都已满足。

若平台、USB 设备或镜像架构不兼容，改用满足条件的 Linux 主机；不要为通过教程而关闭认证或放宽整个 NAS 的目录权限。若唯一现有备份在这台主机，先保存独立副本，再修改加密设置或尝试实验能力。

[教程图片](../images/tutorial/README.md)包含 Raspberry Pi ARM64 和群晖 NAS 的操作示例，图片清单记录各自的来源与验证范围。USB 任务成功和磁盘完成标记不能代替加密清单读取或真机恢复验证；请按所用设备和部署环境分别验收。
