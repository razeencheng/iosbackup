# View backups and export the file list

[简体中文](inspection.zh-CN.md) · [Back to the operations manual](../OPERATIONS.md)

These instructions have moved to [Browse local backup information](backup-browser.md). The Backups page now reads the local overview and unencrypted file list while the phone is offline, builds an index on first viewing, and offers offline CSV download once a complete list has been saved.

The new guide explains preview and search limits, separate read times, encrypted-list restrictions, failure states, and index storage and privacy. CSV contains list records, not device file contents, and is not a restore input. A readable file list does not verify that a backup can be restored.
