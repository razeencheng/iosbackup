# 历史备份

[English](backup-history.md) · [恢复总览](restore.zh-CN.md)

每张设备折叠卡包含 **备份列表 / 任务记录 / 设备设置** 三个页签。首次进入时全部收起；当前浏览器会记住展开的设备和各设备所选页签，包括全部收起的状态，刷新后恢复。没有有效记录时保持收起，新设备默认选中“备份列表”。历史保留在“设备设置”中单独修改，每台设备默认关闭历史功能。

卡片顶部的“立即备份”使用自动模式；任务运行时，同一按钮变为“停止备份”。需要重新请求完整备份时，进入 **设备设置 → 高级操作 → 强制全量备份**，阅读说明后确认。这只影响本次手动备份，不改变自动计划或历史保留策略。任务停止或失败后，有效进度会静态保留并注明其范围；停止时没有进度数据，则合并到暂停提示中。

停止确认按本次任务的存储方式说明影响：历史模式只中断本次独立副本，已保存的历史备份不受影响，任务退出后清理未完成的临时数据；未开启历史时，当前备份集可能因停止而不完整，但此前留存的历史点不受影响。停止会暂停自动备份，直到再次备份或点击恢复链接；后续备份是新任务，不保证接着原进度执行。

## 开启与保留

在“设备设置 → 备份保留策略 → 修改”中开启历史，填写 **1–365 份**，保存设置。默认关闭，份数预填 **2**。按完成时间保留最近 N 次正常备份，包含最新版本；同一天的多次备份分别计数，已固定的另计。没有新正常备份时，已有正常历史不会因时间经过而过期。开启、关闭或将清理历史点时需要确认；不影响清理的修改经服务端预览后直接保存。保存已开启的保留策略也会清理符合条件的点；预览过期后需要重新核对。

提交后，存储准备在后台继续，可以离开页面。设置区会显示准备中、已生效或失败原因；中断后可重试已提交的设置，不会把未完成的复制当作完成。再次打开设置可查看结果。设置保存和历史清理分别显示结果，正在读取的点会延后清理。本地准备分为等待、扫描、复制和核对，与手机备份分开显示；复制百分比只代表本地准备。

每次备份使用独立工作副本。通过快速克隆探测的存储可以共享未变化的数据块；其他存储使用完整复制。三份 100 GB 的副本可能占约 300 GB，另需工作空间。页面展示逻辑数据大小；共享块、旧记录未统计大小和文件系统开销会影响实际占用，不能把该数字当作独占磁盘空间。空间不足时停止新备份，保留受保护的历史。

**固定**会让重要时间点免于自动清理。取消固定只恢复其他保留规则，不会立即删除。固定点、最新正常基线、旧加密版本、手动留存和正在读取的数据，都可能使数量超过设置份数。旁边的 `?` 支持鼠标、键盘和触屏说明。

加密备份中，仅密钥包条目顺序改变不会产生新的保留代。全量备份生成不同密钥包时，应用会尝试用已保存的历史密码在本地核实前后密码一致；核实通过才沿用同一代的份数规则。没有密码、格式不支持或无法核实时，仍能备份，但旧代继续受保护，数量可能超过设置值。已有旧代不会因升级被批量合并或清理。这项核实不解密备份文件，也不开放加密清单检查。

关闭历史后，停止新增和自动清理。已有点转为手动留存，后续普通备份使用独立的可写当前备份集。备份页会单独显示这份当前集，仍可检查并浏览文件清单。再次开启时，只对新增结果应用自动规则。

## 查看、检查与删除

进入“备份列表”，选择日期或“详情”打开抽屉。下载、固定、检查和删除都作用于当前所选点。执行结果、原始备份状态检查和历史保存状态分开显示。**待确认结果**可以导出，清单可读取时支持检查，但不会作为增量基线。导入数据无法确认原始完成时间时，会明确标注。

检查只读：核对元数据，以及可读取清单中的条目和对象是否存在，不逐项验证全部内容哈希，也不证明真机恢复成功。加密或加密状态未知的来源不能执行备份文件检查，原有备份状态检查结果仍可查看。重新检查只更新证据，不会晋升待确认结果或改写数据。检查证据随历史点保留；任务列表另在自身保留期限内记录检查和点 ID。详情可跳转到生成任务，任务也可打开关联备份；任务过期或点被清理时明确提示，不按日期猜测关联。已保存但后续引用更新或清理失败，会保留已保存的结果并注明异常阶段。

取消、超时或读取失败会单独显示为最近一次检查尝试，上一次完成的检查仍保留自己的时间和结论。主动取消按中性状态显示。检查完成但结果写回失败时，当前会话保留新结果并提示未保存；重启可能丢失未保存的结果。完成扫描后发现缺失文件，是“检查完成、发现问题”；不能与检查没有执行完混为一谈。

删除操作位于详情底部的独立区域，需要确认所选日期与当前版本。对话框会提示固定和基线状态；正在使用的点不能删除。明确手动删除可以移除最后一份正常基线，如果当前历史周期内没有同代、正常且元数据可读取的候选点，下次需要全量备份；不会删除其他点或旧密码引用。移除设备不会删除历史：在已移除设备抽屉中选择“查看历史”，无需手机在线，也无需先恢复设备到列表。

## 导出到电脑恢复

1. 点击备份日期或“详情”，再点“完整导出”，在准备就绪后五分钟内点击下载链接。同时最多准备或运行四个会话，实际传输一次一个；繁忙时页面会提示，传输空闲后可重试。
2. 下载 `.tar` 文件，文件名包含设备名、备份时间和简短 ID；原始完成时间未知时使用明确标注的保存日期。电脑需要为完整下载和解压预留空间。其中保留完整原始 `<来源 UDID>/` 目录和加密状态。应用不会把整个文件加载到浏览器内存，也不会在 NAS 上再制作一份同等大小的压缩包。配置、凭据、任务日志和外部索引不在原始来源目录中；保留的解包输出会被排除。
3. “服务端传输已结束”只说明服务端发送结束。请在电脑上确认下载完成；中断或失败后丢弃不完整文件。过期或服务重启后要重新导出，暂不提供断点续传。携带 Range 的请求会明确拒绝，需重新完整下载。
4. 解压到新的暂存目录，保留来源 UDID 和全部内容。不要合并同一设备不同日期的目录。然后按 [Finder](restore-finder.zh-CN.md) 或 [Apple Devices](restore-apple-devices.zh-CN.md) 指引放入电脑备份目录并恢复。加密历史需要当时的密码，可能与当前密码不同。

电脑识别、解密和真机恢复仍需单独验收。整机恢复会影响手机上的较新数据；单独提取照片或消息是另一项能力。
