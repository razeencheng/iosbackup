# 看懂状态、进度和错误

[English](states.md) · [返回手册](../OPERATIONS.zh-CN.md)

本页帮助你决定“继续等待、到手机操作，还是在任务结束后重试”。设备在线、已经配对、备份完成、清单可读和真机恢复成功，需要分别检查。以下名称与当前界面及状态输出对应。

## 连接服务状态

连接服务状态按 USB 和 Wi-Fi 分别显示；共用 usbmuxd2 时两者反映同一服务。下表说明服务状态及相应处理方式。

| 提示 | 含义 | 下一步 |
|---|---|---|
| 未发现已连接设备 | 列表查询成功，结果为空 | 检查设备连接；不会因此重启服务 |
| 连接服务异常 / 设备状态暂时无法确认 | 查询失败，缓存设备不代表当前在线 | 等待检测结果；不要反复解锁或重新配对 |
| 等待当前任务结束 | 已确认异常，但设备操作尚未结束 | 观察原任务进度，恢复不会主动打断它 |
| 正在恢复 | 已取得重启独占权，正在重启和验证服务 | 等待实际枚举、注册和配对验证 |
| 恢复失败，稍后重试 | 重启后的协议查询未成功 | 按提示等待退避，记录错误附近的日志 |
| 自动恢复失败 / 需要人工处理 | 已达到恢复额度或设备工具无法执行 | 检查服务日志和安装，任务空闲后可手动重启 |

查询失败时保留设备名称和备份信息，在线标记变为未知，并暂停接纳受影响的新设备操作；服务故障本身不证明手机已拔出。服务查询、设备信任和备份结果分别验证，成功重启不会自动重跑失败备份。API/SSE 的 `connection_services` 描述服务状态，`presence_known=false` 表示设备在线状态未经确认；不要单独使用缓存的 `online` 布尔值判断。

## 设备状态和任务状态

| 看到的内容 | 能说明什么 | 下一步 |
|---|---|---|
| USB / Wi-Fi 在线 | 最近检测到了设备，或暂时未检测到但仍在等待确认是否离线 | 核对设备名称和连接方式；不代表正在传输 |
| 已配对 | 当前实例有可用的信任关系 | 开始任务时仍可能提示输入锁屏密码或确认信任 |
| 离线 | 程序已无法检测到设备 | 检查线缆、手机和网络；正在运行时先看任务进度 |
| 启动中 `starting` | 请求被接受，正在检查/准备 | 等待明确运行或失败结果；HTTP 成功响应不等于备份完成 |
| 运行中 `running` | 备份任务仍在执行 | 查看阶段和最后活动时间 |
| 成功 `succeeded` / 进度 `completed` | 工具正常退出、出现成功标记，且任务未被取消 | 再核对最近成功时间，按需读取清单 |
| 失败 `failed` | 任务已结束且不成功 | 记录错误，在解决原因后开始新任务 |
| 中断 `interrupted` | 设备断开或运行上下文结束 | 恢复连接后重新开始，不会续传旧会话 |

重启后的界面不是完整的任务历史档案。保留必要的完成记录和脱敏日志；最近成功时间不会因一次失败变成新的成功时间。状态通过服务端事件更新，刷新页面可以重新取得当前快照；关闭浏览器不会取消服务器上的备份。

## 备份进度说明

主进度条表示**整次备份的总体进度** 。工具提供可靠字节数时，另一个**当前文件进度** 表示当前文件传输情况，换文件时可以回到较小值。界面**不显示文件名** ，也**不估算剩余时间** ；缺少可靠文件字节数时只显示总体进度。

| 阶段/显示 | 含义 | 应做什么 |
|---|---|---|
| 正在建立备份会话 `preparing` | 尚未取得可计算的总体进度 | 保持连接，查看手机提示 |
| 等待手机授权 `waiting_authorization` | 等待输入锁屏密码等授权 | 在手机上完成提示；不要把锁屏密码填入备份密码框 |
| 正在向手机发送数据 `sending` | 备份协议向设备发送数据；增量备份会先发送已有清单 | 看最后活动时间，不用总体 0% 判断失败 |
| 正在备份 / 接收数据 `receiving` | 接收设备备份数据 | 保持主机、磁盘、设备和网络稳定 |
| 等待手机处理 `waiting_device` | 等手机处理清单或下一步响应 | 大型加密清单可能等待数分钟；观察无活动期限 |
| 等待设备重新连接 `reconnecting` | Wi-Fi 可见性暂时变化，保留最后可信进度 | 检查手机与网络，等待连接恢复，或任务显示完成、失败、中断 |
| 总体 100% | 进度报告达到 100%，仍可能收尾 | 等待“备份已完成”，不要拔线或关机 |

任务已经结束就**不会自动续传** 。恢复网络后重试属于新任务，可能复用磁盘上的已有备份集，但不等于接回旧连接。当前没有用户取消备份按钮；不要把刷新、退出登录或关闭标签页当成停止操作。

## 无活动超时如何判断

配套镜像中的设备工具会统计协议通信次数和字节数，据此报告收发活动，不记录传输内容。收到协议消息或传输字节可更新最后活动时间；设备可见、心跳、防休眠续租或重复百分比本身不能证明备份活跃。如果自定义镜像中的工具没有相应补丁，应用只能根据工具输出是否变化来判断，准确性较低。

| 无活动阶段 | 环境变量 | 默认期限 |
|---|---|---|
| 手机授权 | `IOSBK_BACKUP_AUTHORIZATION_TIMEOUT` | `5m` |
| 发送/接收 | `IOSBK_BACKUP_INACTIVITY_TIMEOUT` | `10m` |
| 准备/手机处理 | `IOSBK_BACKUP_PREPARATION_TIMEOUT` | `30m` |

它们限制连续无活动时间，不限制仍在传输的总时长，范围均为 `1s`–`24h`。到期后终止本次任务、保留已有备份与最近成功记录，并释放任务占用的资源。后续自动计划仍按条件检查，不会立即无限循环重试。只有确认设备确实需要更长处理时间时，才调整期限，生效方法见[配置参考](configuration.zh-CN.md)。

## 常见错误和下一步

| 错误码/日志 | 含义或可能范围 | 处理入口 |
|---|---|---|
| `backup_busy` | 全局备份并发名额已占用 | 等已有任务结束，再开始一次 |
| `backup_stalled` | 当前阶段超过无活动期限 | 查看手机授权、最后活动、网络；结束后 USB 对照 |
| `device_disconnected` | 设备持续离线导致中断 | 重新连接后开始新备份 |
| `backup_cancelled` | 进程上下文取消或截止，不表示存在取消按钮 | 检查是否重启/停服，恢复服务后重试 |
| `storage_unavailable` | 工具报空间不足、只读或权限不足 | 检查备份挂载的容量、inode、写权限 |
| `device_locked` | 工具报告锁屏/密码提示 | 在手机上按提示输入锁屏密码，或解锁后确认信任 |
| `backup_failed` | 其他备份失败 | 查看同一任务附近日志，保留首个错误 |
| `mobilebackup2 (-4)` | 设备备份通道接收失败；错误本身不能证明根因 | 检查连接和手机状态，做 USB 对照 |
| `MBErrorDomain/207` | 清单读取路径中可能与加密密码或读取条件有关 | 核对[备份加密](encryption.zh-CN.md)，不要通过删除清单“修复” |
| HTTP `401` / `403` | 分别可能为未登录、CSRF 或能力开关拒绝 | 重新登录/刷新，并检查操作适用条件；不要关认证绕过 |

上表没有列出所有 API 错误，错误码也可能随版本变化。具体消息及重现条件仍需记录；详细分步路径见[按症状排错](troubleshooting.zh-CN.md)。

## 读手册时会遇到的词

| 词语 | 本手册中的含义 |
|---|---|
| 实例 | 运行的服务及其配置、主密钥、配对记录、备份数据 |
| 配对 | 手机与本实例建立的信任关系，不是 Apple ID 登录 |
| 备份集 | 保存在设备 UDID 目录下、供工具增量更新的数据；不意味着多个独立时间点 |
| 清单 | 备份中文件的索引；可读不等于每个文件均已校验 |
| 解包 | 把受支持的未加密备份文件复制为可查看目录；不是恢复手机 |
| 实例恢复 | 将服务数据和配置恢复到主机，见[迁移指南](instance-recovery.zh-CN.md) |
| 整机恢复 | 向 iPhone/iPad 写回数据的实验能力，目前还没有在真机上恢复成功的验证记录 |
| Core / Experimental | 功能成熟度，见[功能状态](../FEATURE_STATUS.zh-CN.md)，不是数据恢复保证 |
